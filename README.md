# Neptune Chess Engine

A lightweight, functional chess engine built from scratch in C++. Neptune parses board states, enforces fundamental chess rules, and executes a brute-force lookahead search to make tactical move decisions. 

### Key Features
* **Core Engine:** Custom board representation and move generation enforcing standard chess rules.
* **Search Engine:** Minimax search tree optimized with **Alpha-Beta pruning** for efficient branch elimination.
* **Tactical Evaluation:** Evaluates material and position states to choose optimal candidate moves.

## Tech Stack & Environment
*   **Language:** C++ 
*   **Environment:** Linux / Command Line Interface (CLI)
*   **Compilation:** Standard `g++` compiler
